
# Wanderlust 🏡

Wanderlust is a full-stack accommodation listing web application inspired by Airbnb. It allows users to explore places to stay, view listing details, and manage accommodation listings.

This project is being developed as part of my journey to learn full-stack web development using Node.js, Express, MongoDB, and EJS.

## 🚀 Features

- View all accommodation listings
- View individual listing details
- Create new listings
- Edit existing listings
- Delete listings
- Dynamic pages using EJS
- Reusable EJS layouts and partials
- Responsive UI using Bootstrap
- MongoDB database integration

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/wanderlust.git
```

### 2. Navigate to the project directory

```bash
cd wanderlust
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the application

```bash
node app.js
```

### 5. Open in browser

Visit:

```text
http://localhost:8080
```
